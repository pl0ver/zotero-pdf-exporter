Export PDFs as independent copies or symbolic links. Changes are saved automatically and apply to your next export. Example: Maldacena - 1998 - The Large N Limit of Superconformal Field Theories and Supergravity.pdf Reads Citation Key: from the item’s Extra field. Falls back to Author - Year - Title when no key is available. Live Better BibTeX keys are not queried. Duplicate names receive (2), (3), and so on. Existing files are never overwritten. Successful exports finish silently by default. Errors are always reported. Select items or PDF attachments, right-click, and choose Export PDFs as Copies… or Export PDFs as Symlinks…. Then select a destination folder. Copy creates an independent PDF for sharing. Symlink points to the original file and is supported on macOS only. Finder may display symbolic links as Alias.
